# DylanEstate

## Overview

DylanEstate is a comprehensive online platform designed for builders and property owners to effectively market their properties for sale or rent. The platform offers a user-friendly interface for uploading property details, including high-quality images, and managing listings. Potential buyers and renters can easily explore available properties based on their preferences.

## Technologies used

**React**: A JavaScript library for building user interfaces, providing a component-based architecture for efficient development.

**Tailwind CSS**: A utility-first CSS framework that accelerates the styling process with pre-defined classes.

**Material Tailwind**: A collection of pre-built Material Design components based on Tailwind CSS for a consistent and visually appealing design system.

**React Hook Form**: A library for handling form inputs, validation, and submission, simplifying form management.

**Redux**: A state management library for managing complex application state, ensuring data consistency and predictability.

## key learnings

Implemented image upload functionality. Users can select and upload images within the application. Converted uploaded images to base64 URL format. This efficient encoding improves data handling and web integration. Ensured compatibility with various image formats. Supported common image types like JPEG, PNG, and GIF. Adhered to best practices for image handling and base64 conversion.
